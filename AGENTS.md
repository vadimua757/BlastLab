# AGENTS.md — BlastLab Sandbox

Правила для AI-асистентів. Повні інструкції проєкту — у системному промпті власника; тут стислий виклад.

- Працювати малими TASK (001–011), наступний не починати без підтвердження.
- Архітектура: модульна, data-driven; залежності між asmdef — як у README; без циклів.
- Domain без UnityEngine; бізнес-логіка не в MonoBehaviour; конфіги — ScriptableObject.
- Без глобальних Singleton; явні залежності; pooling для VFX/уламків.
- Продуктивність: спочатку профілювати; без FindObjectOfType у runtime; мінімум GC у гарячих циклах.
- Межі симуляції: тільки абстрактні ігрові ефекти. Жодних реальних характеристик вибухівки/зброї, розрахунків ураження людей чи тварин.
- Не змінювати файли поза завданням, не видаляти без пояснення. Не стверджувати, що збірка успішна, якщо її не запускали.
- Звіт після TASK: що зроблено, файли створено/змінено, рішення, перевірки, що залишилось, як перевірити в Unity.
